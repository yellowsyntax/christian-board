# Christian Board

Personal whiteboard app for sketches, diagrams, and quick notes.

## Built with

This project is **not** a fork of the Excalidraw website. It is a small React + Vite app that embeds the open-source [`@excalidraw/excalidraw`](https://github.com/excalidraw/excalidraw) component.

- App shell / branding: Christian Oduro
- Drawing canvas: [Excalidraw](https://excalidraw.com) (MIT)

## Run locally

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run preview` — preview the build
