# Christian Board

**Christian Board** is a personal whiteboard by **Christian Oduro** for sketching ideas, system diagrams, and quick visual notes.

It’s a personal project — not a commercial product and not a fork of the Excalidraw website. The app is a custom React + Vite shell with my own branding, and it uses the open-source Excalidraw canvas for drawing.

## What it is

- A full-screen dark whiteboard for personal use
- Branded welcome screen for Christian Board
- Preinstalled shape libraries for stick figures, software architecture, and storytelling
- Local-first sketching with export / save support

## What it is not

- Not a rebranded copy of excalidraw.com
- Not a collaborative SaaS product
- Not meant as a drop-in replacement for Excalidraw’s full platform

## Built with

- React + TypeScript + Vite
- [`@excalidraw/excalidraw`](https://github.com/excalidraw/excalidraw) (MIT)

## Preinstalled libraries

Bundled in `public/libraries` and loaded on startup:

- Stick figures
- Software architecture
- Storytelling shapes

## Run locally

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run preview` — preview the build
